# 学习笔记

本目录是源码学习的长期知识库。Issue 和 PR 是过程记录，这里的笔记是按主题组织的概念化沉淀（见 `docs/LEARNING_WORKFLOW.md` 第 12、13 节），引用 Issue/PR 用链接，不复制内容。

## 内容来源约定（自 Step 3 起）

- 笔记以**教程正文与相关评论区**为主要来源，结合本仓库代码实测验证。
- 阅读代码时认为值得记录的内容，在代码中用 `NOTE:` 注释标记，整理笔记时汇总提炼。
- 验证性结论（测试、实验结果）仍以本仓库的 Issue/PR 为证据。
